# 솔리드 피지컬 트레이닝 센터 관리 앱

스케줄, 선수별 출석부, 결제 기록을 관리하는 웹앱이에요.

- 화면: `index.html`, `style.css`, `app.js` (설치·빌드 과정 없음)
- 데이터베이스: Supabase (서울 리전, 프로젝트 `solid-app`)
- 배포: Vercel (깃허브에 올리면 자동 반영)

## 권한
| | 관리자 | 트레이너 |
|---|---|---|
| 스케줄 보기 | 전체 | 전체 |
| 수업 등록·수정·출석 | 전체 | 본인 수업만 |
| 선수 등록·수정 | 가능 | 가능 |
| 결제 기록 | 가능 | 가능 |
| 트레이너 추가·퇴사 처리 | 가능 | 불가 |

권한은 데이터베이스 보안 규칙(RLS)에서 막기 때문에 화면을 우회해도 적용돼요.
가입은 관리자가 트레이너 관리에서 등록한 이메일로만 가능해요.

## 주의
`config.js`에는 공개용(publishable) 키만 넣어요. service_role / secret 키는 절대 넣지 마세요.
